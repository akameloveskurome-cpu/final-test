# credit-gif-pic/

Put ONE picture or GIF here (gif, png, jpg, jpeg, webp or bmp, any file name). It is shown under **Settings > About > Credits**.

- The newest picture in this folder wins. Older ones stay on GitHub but are not used.
- No picture here = nothing shown under Credits.
- It is live: no new APK is needed. The app looks at this folder **every second (1000 ms)** while it is open.
- To send the **same** picture again, add a file named `resend.txt` here (the workflow deletes it again), or use Run workflow with "Send the Credits picture again" ticked.
- Keep the file small (a few hundred KB). The repository is public, so do not upload anything private.
