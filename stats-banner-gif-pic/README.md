# stats-banner-gif-pic/

Put ONE picture or GIF here (gif, png, jpg, jpeg, webp or bmp, any file name). It is shown in a liquid-glass box on the **Home screen, just above Listening Stats**.

- The newest picture in this folder wins. Every new upload replaces the one on screen.
- No picture here = the box stays empty.
- It is live: no new APK is needed. The app looks at this folder **every second (1000 ms)** while it is open.
- To send the **same** picture again, add a file named `resend.txt` here (the workflow deletes it again), or use Run workflow with "Send the Home stats-banner picture again to everybody" ticked.
- Keep the file small. The repository is public, so do not upload anything private.
